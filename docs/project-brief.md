# Project requirements

Audience: early-career data scientists and analysts demonstrating statistics, causal reasoning,
business SQL and fair model evaluation using their Python/SQL stack.

| Requirement | Acceptance evidence |
|---|---|
| Real data, no generated fallback | Pinned source URLs, SHA-256, row counts, real-data integration check |
| Reproducible experiment | Fixed six-test family, adjusted p-values, simultaneous intervals, SRM |
| Prospective planning | Validated binary sample-size function; documented illustrative assumptions |
| Honest targeting | Pretreatment features, independent validation/test, known-propensity evaluation |
| SQL business metrics | Invoice grain, cohort observed-zero handling, RFM, reconciliation tests |
| Time-aware forecasting | Past-only features, fixed split, all model scores, recorded forecast origins |
| Communication | Markdown readouts, charts, JSON and Power BI-ready aggregate CSV |
| Existing-project improvement | StockSense's paired block comparison and service guardrail |

Non-goals: live customer interventions, production loan decisions, private commercial data,
paid APIs, custom web frontend, invented ROI or guaranteed interview outcomes.
